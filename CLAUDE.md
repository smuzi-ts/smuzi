-- TypeScript Rules
Write source code only in .ts files.
Do not create, modify, or generate .js files.
Do not create, modify, or generate .d.ts files.
Type declarations must be defined in .ts files unless explicitly requested otherwise.
Do not generate JavaScript output manually; JavaScript should be produced only by the project's build/compilation process.
all variables names in snake case style
variables for arrowed function names in camel case style
all functions names in camel case style
all types, classes, interfaces on pascal case style
Do not use generic type "any"
